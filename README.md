Welcome to **do_you_redeem** — a lightweight Windows desktop tool that tells you whether a promo code, gift card, or digital voucher is still valid for redemption. No account creation, no cloud dependency, no nonsense. You download, you run, you get your answer.

## 🧰 Usage

1. **Launch** the app by double-clicking `do_you_redeem.exe`.
2. In the main window, you’ll see a single text box labeled **"Enter code or voucher"**.
3. Type or paste the code you want to check (e.g., `SAVE20` or `XMAS2024`).
4. Click the **Check Redeemability** button.
5. The app displays one of three results:
   - ✅ **Redeemable** — the code is active and can be used.
   - ❌ **Expired or Invalid** — the code is dead or never existed.
   - ⚠️ **Unknown** — the app couldn’t verify it. Try again later or check manually.

**Pro tip:** You can check multiple codes in a row. The app keeps a history of your last 20 checks on the left side of the window. Click any past entry to re-check it.

**Keyboard shortcut:** Press `Enter` after typing a code to start the check immediately.

## 🔧 Troubleshooting

**Problem: "Windows protected your PC" warning appears.**
Solution: Click **More info** → **Run anyway**. This is standard for unsigned apps. The file is safe; it’s just not signed with a commercial certificate.

**Problem: The app doesn't open after double-clicking.**
Solution: Make sure you extracted the zip completely. Right-click the folder → **Extract All**. Then try running `do_you_redeem.exe` again. If it still fails, right-click the `.exe` → **Properties** → check **Unblock** at the bottom, then click **Apply** and **OK**.

**Problem: I get "Unknown" for every code I try.**
Solution: This usually means the app can’t reach its verification service. Check your internet connection, then restart the app. If the problem persists, your firewall may be blocking it. Allow the app through Windows Defender Firewall (private networks only).

**Problem: The app window is too small or blurry.**
Solution: Right-click `do_you_redeem.exe` → **Properties** → **Compatibility** → check **Override high DPI scaling behavior** → set to **System**. Apply and restart.

**Problem: I accidentally deleted the extracted folder.**
Solution: Just download the zip again and repeat the extraction steps.
